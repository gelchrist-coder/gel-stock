## 🚀 THE 3-STEP DEPLOYMENT PLAN

### Step 1: Deploy Backend to Render.com (5 minutes)
```
1. Create account at https://render.com (free)
2. Create Web Service
3. Connect GitHub: gelchrist-coder/gel-stock
4. Configure:
   - Name: gel-stock-api
   - Environment: PHP
   - Start: cd api && php -S 0.0.0.0:10000
5. Add environment variables (from .env.example)
6. Click "Create Web Service"
7. Wait for "Live" status

Result: https://gel-stock-api.onrender.com/api/* (live)
```

**Read**: `CLOUD_DEPLOYMENT_COMPLETE.md` (Step 2-3)

---

### Step 2: Configure DNS (30 seconds + 24-48 hour wait)
```
1. Go to your domain registrar
2. DNS Settings
3. Add CNAME Record:
   Name: @
   Value: gelchrist-coder.github.io
4. Save changes
5. Wait 24-48 hours for propagation

Verify: nslookup gel-stock.me (should resolve)
```

**Read**: `GEL-STOCK-ME_DNS_SETUP.md` (registrar guides included)

---

### Step 3: Test Full System (10 minutes)
```

2. Register new account

4. Login from different device

Expected: All features work, data in PostgreSQL
```
